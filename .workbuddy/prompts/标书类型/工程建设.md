# 工程建设类标书提示词模板

<!-- 预估 tokens: ~900 | 加载条件: 用户明确这是工程建设/施工类项目 -->

## 类型核心特征

工程建设采购的核心是 **「施工组织 + 质量安全 + 进度成本」** 三角平衡。评标委员会最关注：
- 施工方案是否针对项目现场条件（不是套通用模板）
- 质量和安全措施是否可落地执行（不是口号）
- 进度计划是否可量化验证（里程碑可度量）

**风格导向**：规范驱动，引用国标/行标。用具体工法和数据替代泛泛之谈。是所有标书类型中对「标准化引用」要求最高的。

**关键法规**：《招标投标法》《建设工程质量管理条例》《建设工程安全生产管理条例》——提示词涉及合规性要求时自动引用相关条款。

## 统一评分框架映射

| 标准评分维度 | 工程建设对应章节 | 典型权重 | 高分关键 |
|-------------|----------------|---------|---------|
| 整体方案设计 | 施工组织设计 | 25-35% | 针对现场条件的差异化方案，不是模板 |
| 关键技术方案 | 施工组织设计（分项工法） | 15-20% | 每项工艺引用标准号+可量化参数 |
| 项目实施计划 | 进度计划与保障 | 10-15% | 关键路径 + 里程碑用实物量定义 |
| 项目团队配置 | 项目团队 | 10-15% | 一建证书编号 + 同类项目竣工证明 |
| 培训与运维 | 安全文明施工（安全培训部分） | 5-10% | 安全培训计划和演练记录机制 |
| 质量安全保障 | 质量管理 + 安全管理 | 15-20% | 标准号引用 + 控制点量化 + 可检查措施 |

## 废标风险清单

| 风险项 | 检查点 | 后果 |
|--------|--------|------|
| 施工资质不符 | 资质等级是否匹配项目规模 | 直接废标 |
| 项目经理无有效一建 | 一建专业是否对口 + 是否在注册有效期内 | 直接废标 |
| 安全生产许可证过期 | 有效期截止日 > 投标截止日 | 直接废标 |
| 业绩不满足 | 同类业绩数量/规模/竣工时间是否符合要求 | 资格审查不通过 |
| 投标报价超限价 | 报价是否超过最高投标限价 | 直接废标 |
| 工期不响应 | 承诺工期 > 招标文件要求工期 | 符合性审查不通过 |
| 人员社保缺失 | 拟派主要人员近3个月社保证明不全 | 人员资格审查不通过 |

## 章节提示词

### 一、施工组织设计（核心章节，权重最大）

```
你是本项目施工组织设计负责人。请撰写「施工组织设计」章节：

【约束】
- 针对 {项目所在地} 的地理、气候、交通条件做针对性说明
  → 反例：「本项目地处XX市，交通便利」——这不是针对性说明
  → 正例：「项目南侧紧邻XX主干道，高峰期限行，大宗材料进场须安排在22:00-05:00，需提前24h报备交管部门」
- 施工总平面布置：描述功能分区（材料堆放区、加工区、办公区、生活区）并说明分区间的动线逻辑
- 主要施工方案至少覆盖：基础工程、主体结构、机电安装、装饰装修
- 每个分项工程必须四步说明：施工工艺 → 选用标准（含标准号） → 检验方法 → 验收标准
- 关键设备配置：列出设备名称/型号/数量/进出场时间，按施工阶段分组
- 禁止：「合理布置」「科学安排」——这是无效描述，评审会直接跳过
- 禁止：照搬教科书式施工流程（不分项目条件一律土方→基础→主体）
- 必须：从招标文件/现场踏勘报告中提取 ≥3 个本项目特有难点，写针对性应对措施
- 风格：操作手册式，按实际施工顺序写，读完能直接在工地执行
```

### 二、质量管理体系

```
你是本项目质量负责人。请撰写「质量管理体系」章节：

【约束】
- 引用具体标准号（GB50300、GB50204、GB50210等），不可笼统说「符合国家标准」
- 质量控制点按分部工程列出，每点必须包含五个字段：
  分项工程 | 控制项目 | 允许偏差（数值） | 检测方法 | 检测频率
  → 要求：不少于 12 个控制点
- 材料进场检验流程须覆盖：报验 → 见证取样 → 送检 → 检测报告出具 → 合格判定 → 材料使用
- 每个环节标注责任人角色（不是姓名，是职责角色如"质检员"）
- 禁止：「严格质量管理」「确保工程质量」——评审认定为零信息
- 禁止：标准号写错或引用已废止标准——生成后逐条核验标准号有效性
- 风格：检验批式的技术文档
```

### 三、安全管理与文明施工

```
你是本项目安全负责人。请撰写「安全管理与文明施工」章节：

【约束】
- 危险源辨识按分部工程分组，每组列出：
  危险源描述 | 可能导致的事故类型 | 风险评估等级（低/中/高/重大） | 控制措施
  → 要求：不少于 15 项
- 专项安全方案：明确指出哪些分项必须编制专项方案并组织专家论证
  → 必须覆盖：深基坑（深度>5m）、高支模（高度>8m或跨度>18m）、塔吊安拆、脚手架
- 安全投入清单量化：安全帽X顶、安全带X条、防护网X㎡等，不与报价清单矛盾
- 文明施工措施分类量化：
  → 围挡：高度、材质、宣传内容比例
  → 降尘：洒水频率、雾炮配置数量、裸土覆盖率
  → 降噪：噪音限值（dB）、夜间施工限制时段
  → 排污：沉淀池规格、排水路径
- 禁止：「加强安全教育」「重视安全生产」——每条措施必须是"谁在什么时间做什么"
- 必须：按《建筑施工安全检查标准》(JGJ59) 的检查表结构组织
- 风格：可逐条勾选确认的执行清单
```

### 四、进度计划与保障

```
你是本项目计划管理负责人。请撰写「进度计划与保障」章节：

【约束】
- 总工期分解为里程碑节点，每个节点必须有可验证的完成标准
  → 反例：「基础工程完成」——不可验证
  → 正例：「±0.00 以下结构全部完成，基础分部工程验收合格」
- 关键路径上的工序说明：工序名称 → 工期 → 紧前工序 → 紧后工序 → 关键制约因素
- 劳动力计划：按施工阶段列出各工种人数和进退场时间，高峰期总人数不超过合理峰值
- 工期保障按三维度写：
  → 组织保障：赶工预案（增加班组/延长工时/平行施工的具体方案）
  → 技术保障：冬季施工（混凝土保温措施）、雨季施工（排水和防护措施）、高温施工（防暑降温措施）
  → 资源保障：备用供应商名单、备用设备租赁渠道
- 禁止：只说「不可抗力因素」而不写具体预案
- 必须：注明每个里程碑延误后的补救措施和极限赶工方案的代价
- 风格：横道图语言描述 + 资源配置表
```

### 五、项目团队

```
你是本项目拟派项目经理。请撰写「项目团队」章节：

【约束】
- 项目经理（必填）：
  → 一级建造师注册证书编号（与专业对口）
  → 安全B证编号
  → 已完工的同类项目业绩（名称+规模+竣工时间+担任角色）
  → 目前无在建项目承诺
- 技术负责人：高级工程师及以上职称，列出技术专长和代表性项目
- 五大员到岗承诺：施工员/质量员/安全员/材料员/资料员，每人列出上岗证编号
- 所有人员附近3个月社保缴纳证明
- 禁止：「参与过XX项目」——必须说明担任的核心角色（项目经理/技术负责人/生产经理）
- 禁止：团队成员之间存在同一时段履职冲突（一个人同时在两个项目）
- 必须：所有证书编号支持全国建筑市场监管公共服务平台查询
- 风格：标准投标人员表格式，信息密度高
```
