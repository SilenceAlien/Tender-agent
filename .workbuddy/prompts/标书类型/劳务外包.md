# 劳务外包类标书提示词模板（v1 — 基于真实中标标书提炼）

<!-- 预估 tokens: ~1200 | 加载条件: 用户明确这是劳务外包/劳务派遣/劳务管理服务类项目 -->

## 类型核心特征

劳务外包的核心是 **「合规用工 + 全流程人员管理 + 风险兜底」** 三位一体。评标委员会最关注：
- 投标人是否具备合法经营资质（劳务派遣许可证/人力资源服务许可证），能否承担用工主体全部法律责任
- 人员管理流程是否覆盖入职→在职→离职全生命周期，每个环节合法合规、可追溯
- 劳动争议、工伤事故等风险是否有完善的预防机制和应急处置能力，能否做到"风险不传导至招标人"

**风格导向**：合规驱动，流程化，可审计。劳务外包是最容易写成"承诺大全但流程空洞"的类型——评标专家看的不是你承诺了什么，而是你具体怎么做、谁来做、出了问题怎么兜底。

**适用场景**：劳务管理服务、劳务派遣、岗位外包、业务外包、人力资源外包、食堂劳务外包、保安保洁劳务外包、仓储物流劳务外包、生产线劳务外包等以人力输出为核心的采购项目。

**与「服务采购」模板的关系**：服务采购模板侧重"项目交付型服务"（如咨询服务、培训服务），本模板侧重"人力输出型服务"（以人员管理为核心）。两者有交叉但重心不同——劳务外包的核心风险在用工合规而非服务交付质量。

**关键法规**：《中华人民共和国劳动法》《劳动合同法》《社会保险法》《劳务派遣暂行规定》《工伤保险条例》《流动人员人事档案管理服务规定》——提示词涉及合规性要求时自动引用相关条款。

## 统一评分框架映射

| 标准评分维度 | 劳务外包对应章节 | 典型权重 | 高分关键 |
|-------------|----------------|---------|---------|
| 整体方案设计 | 服务方案（项目概述+服务目标+团队架构） | 15-25% | 需求理解深度 + 用工规模量化 + 四维目标展开 + 团队分工到组 |
| 关键技术方案 | 服务方案（职责分工+流程描述） | 15-25% | 六大职能组覆盖全生命周期 + 每组流程可执行 + 法规引用准确 |
| 项目实施计划 | 服务方案（团队保障+培训方案）+ 应急保障方案 | 10-20% | 人员到位计划 + 培训分层 + 多场景应急 |
| 项目团队配置 | 服务方案（团队成员背景） | 10-20% | 核心人员资质 + 同类项目经验 + 量化成就 |
| 培训与运维 | 服务方案（安全培训+技能培训） | 5-10% | 岗前培训 + 在岗培训 + 考核机制 |
| 质量安全保障 | 服务方案（服务承诺）+ 应急保障方案 | 5-15% | 六维承诺 + 工伤预案 + 劳动争议预防 |

**重要说明**：劳务外包类项目的评分权重因采购人而异。铁路/国企/央企采购通常采用"物资采购招标"格式（如本项目按招标编号GLZ2026-26归类为"物资采购"），评分侧重资格审查和服务方案；政府采购通常采用"服务类"评分，价格权重可能高达30-70%。使用本模板时需根据具体招标文件的评分标准调整策略重心。

## 废标风险清单

| 风险项 | 检查点 | 后果 |
|--------|--------|------|
| 经营许可缺失 | 劳务派遣经营许可证 / 人力资源服务许可证是否在有效期内，证书编号是否可查 | 直接废标 |
| 业绩不满足 | 同类业绩数量/规模/服务人数是否符合招标文件要求，合同签订日期在要求年限内 | 资格审查不通过 |
| 财务数据不达标 | 近2-3年营业额/审计报告是否满足招标文件要求 | 资格审查不通过 |
| 诉讼仲裁未披露 | 近年败诉的合同诉讼/仲裁是否如实填报 | 诚信风险，可能废标 |
| 信誉不满足 | 是否被列入严重违法失信企业名单/失信被执行人/行贿犯罪记录 | 直接废标 |
| 偏差表未响应 | 商务和技术偏差表是否逐条响应，是否有实质性偏差未声明 | 符合性审查不通过 |
| 报价方式错误 | 是否按招标文件要求的计价单位报价（人/月 vs 人/年 vs 总包价），增值税率是否正确 | 废标或报价分零分 |
| 人员规模不匹配 | 承诺提供的人员数量是否满足招标文件预测需求量 | 方案不合理扣分 |
| 投标保证金不符 | 保证金金额/形式/到账时间是否符合招标文件要求 | 直接废标 |
| 关联企业未披露 | 与投标人存在控股/管理关系的关联企业是否如实填写 | 诚信风险 |

## 章节提示词

### 一、投标函

```
你是投标文件编制负责人。请撰写「投标函」章节：

【必须包含的内容】
1. 项目信息声明 — 项目名称、招标编号、包件号必须与招标文件完全一致
2. 投标报价 — 含税人民币（大写+小写），注明增值税税率及是否提供增值税抵扣凭证
3. 投标文件组成 — 逐项列出投标文件包含的各组成部分
4. 响应承诺 — 声明除偏差表列出的偏差外，响应招标文件全部要求
5. 投标有效期承诺 — 承诺在招标文件规定的有效期内不撤销投标文件
6. 中标后承诺 — 签订合同/不提附加条件/提交履约保证金/按期完成义务
7. 评标价接受声明 — 接受评标委员会根据评标办法修正和评定评标价
8. 真实性声明 — 声明投标文件内容完整、真实、准确
9. 投标人信息 — 名称（盖单位章）、法定代表人签字、地址、网址、电话、传真、邮政编码

【硬约束】
- 必须：项目名称、招标编号、包件号逐字核对，不可有任何差错
- 必须：投标报价金额大写与小写必须一致
- 必须：增值税税率按招标文件要求填写（劳务外包通常为6%或按当地政策）
- 禁止：投标函中的承诺与后续章节内容矛盾
- 风格：正式函件式，语言庄重严谨
```

### 二、资格审查资料（劳务外包类废标的头号风险区）

```
你是投标资格审查负责人。请编制「资格审查资料」章节：

【必须包含的7个子项】
1. 基本情况表：
   → 投标人名称/注册资金/成立时间/注册地址/员工总数/联系方式
   → 法定代表人信息（姓名/电话）
   → 资质证书：劳务派遣经营许可证 + 人力资源服务许可证（类型/等级/证书号）
   → 企业税号/基本账户开户银行及账号
   → 近三年营业额（逐年列出）
   → 关联企业情况（控股/管理关系的不同单位必须如实填写）

2. 近年财务状况表：
   → 按招标文件要求年度提供审计报告（通常近2-3年）
   → 审计报告须完整附后，关键财务数据可在表中摘要

3. 近年完成的类似项目情况表（每个项目一表）：
   → 物资名称/项目名称/项目所在地/买方名称/买方联系人及电话
   → 合同价格/合同签订日期/交货起止日期
   → 项目概况及投标人履约情况（必须写明服务人数、服务内容、履约结果）
   → 附合同盖章页

4. 正在承接的项目情况表（每个项目一表）：
   → 同上格式，注明履行截止日期"至今"
   → 附合同盖章页或近期发票

5. 近年发生的诉讼及仲裁情况：
   → 按招标文件要求年限（通常1-3年）如实填报
   → 无诉讼也必须填写"无"并盖章确认
   → 有败诉案例必须详细说明：年份/采购人名称/诉讼缘由/争议事项/争议金额/胜诉或败诉

6. 投标人的信誉情况表：
   → 国家企业信用信息公示系统未被列入严重违法失信企业名单的查询结果截图
   → "信用中国"或"中国执行信息公开网"未被列入失信被执行人名单的查询结果截图
   → "中国裁判文书网"近三年行贿犯罪行为查询结果截图
   → 如招标人为铁路系统：补充国铁集团"信用评价结果"未被确定在处罚期内的声明

7. 其他材料：
   → 营业执照
   → 劳务派遣经营许可证
   → 人力资源服务许可证
   → 基本户开户许可证
   → 企业信用等级证书（如有）
   → 其他资质证书/社会荣誉（如有）

【硬约束】
- 必须：所有证书编号、有效期限逐条核对，确保在有效期内
- 必须：营业额数据与审计报告一致，不可自行调整
- 必须：业绩项目的"交货起止日期"和"合同签订日期"逻辑自洽
- 禁止：遗漏关联企业（招标人可通过工商系统核查）
- 禁止：诉讼仲裁情况隐瞒不报（招标人可通过裁判文书网核查）
- 禁止：信誉截图过期（通常要求查询日期在投标截止前30日内）
- 风格：表格式，信息完整，证明材料齐全
```

### 三、服务方案（技术标核心，权重最大）

```
你是本项目劳务管理服务方案设计师。请撰写「服务方案」章节：

【必须包含的结构】
1. 项目概述 — 用自己的语言重述项目核心需求
   → 必须：写明招标人用工需求的具体数字和岗位类型（如"预测年度劳务服务人员需求1755人，包含电焊工、车辆钳工、车辆电工、铆工等"）
   → 必须：列出服务范围的全部核心内容（劳动合同管理、档案管理、人员名册提交、劳动管理、劳动争议处理、人员教育、上岗培训等）
   → 标准：写完后问自己「这段话能直接套到另一个项目上吗」→ 如果「是」→ 不够具体

2. 服务目标 — 按四维度展开，每项目标≤3句话：
   → 合规目标：引用具体法律法规名称，承诺"全流程合规可控"
     · 反例："确保合法合规"——没有信息量
     · 正例："严格遵守《劳动法》《劳动合同法》《流动人员人事档案管理服务规定》，依法完成劳动合同签订、档案管理，确保劳务管理全流程合规可控"
   → 高效目标：量化流程时效，承诺"降低招标人管理成本"
     · 正例："优化劳务管理流程，精准提交人员名册及相关资料，高效处理劳动管理事务，保障劳务人员有序到岗、规范履职"
   → 安全目标：覆盖人员安全和经营秩序安全
     · 正例："强化劳务人员安全教育培训，杜绝因人员操作不当、违规上岗引发的安全隐患；妥善处理劳动争议，保障招标人生产经营秩序稳定"
   → 优质目标：强调人员素质和服务效果
     · 正例："确保劳务人员资质达标、素养合格，严格遵守招标人工作制度，保守商业秘密，助力招标人提升整体运营效能"

3. 服务团队架构 — 组织层级图(文字描述或图示)
   → 层级：项目负责人 → 各专项职能组 → 组员
   → 每个层级说明管理职责和管理幅度

4. 服务团队主要职责分工 — 按六大职能组展开（根据项目实际增减）：
   → 组1：项目负责人 — 全面统筹/对接招标人/制定计划/团队管理考核
   → 组2：入职资料及劳动合同及档案管理组
     · 劳动合同：依法订立书面合同，确保条款合法规范，及时归档备案
     · 档案管理：按《流动人员人事档案管理服务规定》办理，"一人一档"，库房/阅档/整理/办公场所严格分开，防火防潮防盗防损坏
     · 档案归档时限：合格材料一般在2个月内完成归档，不合格材料及时退回补充
     · 人员名册：载明姓名/性别/出生日期/身份证号/健康状况/文化程度/职业资格/技能等级/工作经历
   → 组3：薪酬数据及社保增减组
     · 每月薪酬数据核对、个税申报及社保转移处理
     · 社保增减流程：增员/减员/转移的时效和操作规范
   → 组4：新员工安全培训及日常技能培训
     · 法律法规教育 + 招标人单位制度解读 + 商业秘密保护教育
     · 岗前培训 + 在岗定期培训，考核合格方可上岗
     · 如需委托招标人培训，说明委托流程和费用承担
   → 组5：劳动争议及工伤管理组
     · 建立劳动争议预警机制，主动排查隐患
     · 处理劳资纠纷、合同解除纠纷，通过协商/调解/法律途径解决
     · 定期开展思想动态排查，提升人员稳定性
   → 组6：驻厂管理组（如有驻场需求）
     · 驻扎招标人指定场所，负责现场日常管理/考勤统计/问题反馈
     · 协助现场安全教育/纪律监督，搭建沟通桥梁
   → 每组说明：职能组名称 | 核心职责(3-5条) | 关键工作流程 | 输出物

5. 团队保障措施：
   → 人员保障：核心岗位经验年限要求 + 专业资质要求
   → 培训保障：法律法规/劳务管理规范/招标人制度/行业知识的定期培训计划

6. 团队成员背景 — 每人按简历式呈现：
   → 姓名 | 职责 | 从业年限 | 专业证书(名称+编号) | 同类项目经验 | 量化成就
   → 量化成就示例："主导跨部门协作统筹推进招聘管理、薪酬核算及考勤体系优化"
   → 量化成就示例："统筹300+人员薪酬核算，开发自动化对账流程提升核算效率30%"
   → 量化成就反例："具有丰富的人力资源管理经验"——完全不可验证

7. 服务承诺 — 逐条列出（不少于6条）：
   → 合规承诺：遵守法律法规 + 具备合法有效许可证 + 提供审计财务报表及业绩
   → 质量承诺：服务标准 + 人员资质达标 + 主动接受监督考核
   → 效率承诺：快速响应 + 按时提交名册资料 + 到岗及时
   → 保密承诺：保守商业秘密/技术信息/管理信息 + 建立保密管理制度
   → 责任承诺：未达标整改 + 整改不达标按合同追究违约责任
   → 信誉承诺：未被列入失信名单 + 无行贿犯罪记录 + 遵守信誉要求
   → 每条承诺格式：「我们承诺XX → 通过YY机制保障 → 如有违约按ZZ处理」

【硬约束】
- 禁止：「设置项目负责人和各专项小组」——没说清楚每个组具体做什么
- 禁止：「具有丰富经验」——必须用年限/项目数/证书编号替换所有形容词
- 禁止：服务目标用「提供优质服务」——按四维度展开后给具体指标
- 必须：服务承诺和保障措施一一对应——每一句承诺都能追溯到方案中的具体机制
- 必须：所有流程描述到「一个新入职员工读完就能执行的粒度」
  → 反例：「每月按时完成薪酬核算」
  → 正例：「每月X日前，薪酬专员从考勤系统导出数据→核对加班/请假/调休→代入薪资公式→编制工资表→经项目负责人审核→提交甲方确认→X日前完成发放」
- 必须：引用法律法规时使用全称（如《中华人民共和国劳动法》而非《劳动法》），首次引用用全称，后续可简称
- 风格：方案书式，读完能直接作为团队的SOP手册
```

### 四、应急保障方案（劳务外包类最容易被忽视的章节）

```
你是项目风险管控负责人。请撰写「应急保障方案」章节：

【必须包含的应急场景（不少于4个）】
根据劳务外包项目特点选择或自定义：

1. 业务量骤增应急：
   → 触发条件：招标人临时增加X%用工需求
   → 响应措施：人才储备库规模/各地办公室调配能力/招聘团队响应时限/培训场地保障
   → 正例："本公司会提前进行人才储备，各地办公室可以及时供应以及调动人才，有专业的招聘团队及培训场地能及时响应，满足人才需求计划"

2. 工伤事故应急（劳务外包核心风险）：
   → 触发条件：劳务人员发生工伤事故
   → 响应流程（必须分步骤）：
     · 第一步-及时救治：确保受伤员工得到及时有效的医疗救治，报告工伤
     · 第二步-收集证据：配合调查，协助申请工伤认定、劳动能力鉴定
     · 第三步-协商赔偿：积极与员工协商工伤赔偿（医疗费/误工费/护理费/伤残补助金等）
   → 预防措施：平时加强安全意识宣贯，提高安全意识理念
   → 关键承诺：工伤事故由投标方独立处理，不影响招标人生产经营秩序

3. 关键人员流失应急：
   → 触发条件：核心岗位人员突然离职
   → 响应措施：替代人选安排/替补到岗周期/交接机制/知识传承

4. 劳动争议应急：
   → 触发条件：出现劳资纠纷/集体争议/劳动合同解除纠纷
   → 响应流程：预警机制→介入协调→协商调解→法律途径→善后处理
   → 关键承诺：争议由投标方独立负责解决，确保不影响招标人正常秩序

5. 服务质量滑坡应急（如有）：
   → 触发条件：招标人投诉/满意度下降/考核不达标
   → 响应措施：预警机制→改进计划→甲方沟通→整改验证

6. 政策法规变更应急（如有）：
   → 触发条件：新法规要求调整用工方式或社保政策
   → 响应措施：快速响应/合规调整/人员宣贯/流程更新

每个场景按五要素结构写：
触发条件(可观测的信号) → 影响评估(对招标人业务的具体影响) → 响应流程(分步，每步责任人+时限) → 恢复目标(恢复到正常状态的标准) → 事后复盘

【硬约束】
- 禁止：「及时处理」「妥善应对」——应急方案的价值在于「预案」中的「预」，不是「事后处理」
- 禁止：只写1-2个场景（看起来像套模板凑数）
- 必须：工伤应急方案是劳务外包类的必备场景——不写工伤预案=不懂劳务外包
- 必须：每个预案让评标专家产生「这个团队真遇到过这种状况并处理过」感觉
- 风格：故障场景剧本式，每个场景可独立演练
```

## 劳务外包 vs 服务采购 差异对照

| 维度 | 劳务外包（本模板） | 服务采购（通用模板） |
|------|-------------------|-------------------|
| 核心交付物 | 人（劳务人员） | 服务（服务行为/服务结果） |
| 核心风险 | 用工合规、劳动争议、工伤事故 | 服务质量、交付时效 |
| 必备资质 | 劳务派遣许可证 + 人力资源服务许可证 | 行业许可证（视项目而定） |
| 团队描述重心 | 职能组分工（合同/薪酬/培训/争议/驻厂） | 岗位配置（项目经理/业务主管/专项岗位） |
| 应急预案重心 | 工伤事故 + 劳动争议 + 业务量骤增 | 服务中断 + 质量滑坡 + 人员流失 |
| 法规引用 | 劳动法/劳动合同法/社保法/工伤保险条例 | 视行业而定 |
| 承诺重心 | 合规承诺 + 保密承诺 + 责任兜底 | 质量承诺 + 时效承诺 + 满意度承诺 |
| 评分重心 | 资格审查（资质/业绩/信誉）权重高 | 服务方案权重高 |

## 劳务外包子类型适配指引

| 子类型 | 服务方案侧重 | 特有风险 | 特有资质 |
|--------|-------------|---------|---------|
| 工业生产线劳务外包 | 安全培训 + 技能匹配 + 驻厂管理 | 工伤事故率高 + 人员流动性大 | 劳务派遣许可证 |
| 食堂餐饮劳务外包 | 食品安全 + 营养配餐 + 人员健康证 | 食品安全事故 + 交叉污染 | 食品经营许可证 + 健康证 |
| 保安保洁劳务外包 | 安全防范 + 清洁标准 + 排班制度 | 安全事件 + 人员缺岗 | 保安服务许可证（如需） |
| 仓储物流劳务外包 | 岗位匹配 + 效率管理 + 安全操作 | 货物损坏 + 操作事故 | 视货物类型而定 |
| 人力资源外包（HRO） | 招聘流程 + 薪酬社保 + 档案管理 | 数据安全 + 社保差错 | 人力资源服务许可证 |
| 业务流程外包（BPO） | 流程标准化 + 质量管控 + 数据安全 | 业务中断 + 信息泄露 | 视业务类型而定 |
