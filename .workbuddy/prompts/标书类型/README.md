## v3 更新内容（2026-07-04）

新增「劳务外包」模板，基于真实中标标书（2026年广州铁道车辆有限公司劳务管理服务采购）提炼：
1. **六大职能组分工模型** — 覆盖入职→在职→离职全生命周期（合同档案/薪酬社保/培训/争议处理/驻厂管理）
2. **劳务外包 vs 服务采购差异对照表** — 明确两类模板的适用边界和核心差异
3. **劳务外包子类型适配指引** — 覆盖工业生产线/食堂餐饮/保安保洁/仓储物流/HRO/BPO 六大子类型
4. **工伤事故应急标准流程** — 劳务外包类核心风险的三步处置流程（救治→取证→赔偿）
5. **废标风险清单强化** — 新增劳务派遣许可证/人力资源服务许可证/关联企业披露/诉讼仲裁等专项检查点

## v2 更新内容（2026-06-28）

每个模板新增三个标准结构：
1. **统一评分框架映射** — 将所有类型的评分映射到政府采购标准6维评分体系
2. **废标风险清单** — 列出该类型最常见的废标风险和检查点
3. **信创合规矩阵** — 软件开发/系统集成模板补充信创适配指引

约束强化：
- 所有「禁止」规则附带反例→正例对比
- 量化要求用公式或具体数字替代形容词
- 每类评分权重改为典型区间而非单一值

## 使用方式

1. 用户告知标书类型（如「这是软件开发类项目」）
2. 上下文注入 Skill 加载对应类型模板
3. 同时加载通用模板（格式规范.md / 评分响应模板.md）
4. 类型模板提供「怎么写」，通用模板提供「怎么评分怎么排版」

## 混合型项目处理

| 混合场景 | 方案 |
|---------|------|
| 建设 + 运维 | 软件/工程模板处理建设部分，运维模板处理运维部分 |
| 系统集成 + 软件开发 | 系统集成模板覆盖总体，软件开发模板覆盖软件子项 |
| 服务 + 货物 | 分别按各自类型的规则处理对应部分 |
| 劳务外包 + 服务采购 | 劳务外包模板覆盖人员管理部分，服务采购模板覆盖服务交付部分 |
| 劳务外包 + 食堂餐饮 | 劳务外包模板覆盖用工管理，叠加食品安全/健康证等专项要求 |

## 模板通用结构

每个类型模板包含：
- **类型核心特征**：评标最关注什么，风格导向，信创提示（如适用）
- **统一评分框架映射**：标准6维评分的对应章节和权重
- **废标风险清单**：该类型最常见的废标风险和检查点
- **章节提示词**：带约束的角色化 prompt（含反例→正例对比）
- **信创合规矩阵**（软件开发/系统集成）：国产化适配清单
