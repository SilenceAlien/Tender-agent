# 货物采购类标书提示词模板

<!-- 预估 tokens: ~850 | 加载条件: 用户明确这是货物采购项目 -->

## 类型核心特征

货物采购的核心是 **「参数响应 + 认证合规 + 交付可控」** 。评标委员会最关注：
- 技术参数是否逐条完整响应（跳过硬性指标 = 废标）
- 质量认证链条是否完整可查（从生产资质到检测报告）
- 交付计划是否有产能数据支撑（不能是空头承诺）

**风格导向**：参数级精确，用数据和证书说话，少用形容词。货物采购是所有类型中对「逐条响应」要求最严的——没有模糊空间。

---

## 统一评分框架映射

| 标准评分维度 | 货物采购对应章节 | 典型权重 | 高分关键 |
|-------------|----------------|---------|---------|
| 整体方案设计 | —（货物不强调方案设计） | — | 不适用 |
| 关键技术方案 | 产品技术参数响应 | 35-45% | 逐条三列响应 + 正偏离突出 + 检测报告支撑 |
| 项目实施计划 | 生产与交付能力 | 10-20% | 产能计算公式 + 批次排期表 + 物流方案 |
| 质量安全保障 | 产品质量与合规 | 10-15% | 证书编号齐全 + 有效期核查 + 供应链可控 |
| 项目团队配置 | —（货物不强调团队） | — | 技术服务人员资质附在售后章节 |
| 培训与运维 | 售后与质保 | 5-10% | 网点分布 + 故障分级响应 + 备件清单量化 |

**特殊说明**：货物采购中「价格分」通常占比 30-40%，是所有类型中最高的。技术参数正偏离的附加分可能成为价格劣势的逆转点。

---

## 废标风险清单

| 风险项 | 检查点 | 后果 |
|--------|--------|------|
| 关键参数不满足 | 带 ★ 号或标有「不可偏离」的参数是否逐条满足 | 直接废标 |
| 强制性认证缺失 | CCC/生产许可证/特种设备许可证等是否在有效期内 | 直接废标 |
| 投标产品不在允许范围内 | 是否是指定品牌范围或同等档次产品（同等论证是否充分） | 资格审查不通过 |
| 非标定制未说明 | 定制产品的检测报告/样品是否按要求提供 | 符合性审查不通过 |
| 备件价格畸高 | 备件报价是否明显高于市场价（防止「低价中标、天价备件」） | 异常低价审查 |
| 交付周期超限 | 承诺交付周期 > 招标文件要求的最长交付期 | 符合性审查不通过 |
| 证书过期 | 认证证书/检测报告有效期截止日 < 投标截止日 | 技术参数不通过 |

## 章节提示词

### 一、产品技术参数响应

```
你是投标产品的技术负责人。请撰写「技术参数响应表」章节：

【约束】
- 逐条对照招标文件技术参数要求，采用「招标要求 → 投标响应 → 偏离说明」三列格式
- 正偏离必须标注并说明：偏离幅度（数值）、带来的额外价值、支撑证据（检测报告编号）
- 负偏离必须诚实说明：偏离幅度、原因（客观技术限制）、提出的替代方案和等价论证
- 每条关键参数必须匹配一份检测报告编号或认证证书编号
- 禁止：任何一条参数无响应——即使完全满足也必须写「无偏离，完全响应」
- 禁止：用「优于」「领先」等无量化词汇替代具体参数值
  → 反例：「性能优于招标要求」
  → 正例：「主频3.2GHz，超出招标要求(3.0GHz)6.7%，见检测报告XX号」
- 禁止：标注正偏离但检测报告不支持——评审发现 = 虚假应标
- 必须：生成后逐条核对是否遗漏——漏一条带★的参数 = 废标
- 风格：表格化，一条一证，零模糊空间
```

### 二、产品质量与合规

```
你是质量体系负责人。请撰写「产品质量与合规」章节：

【约束】
- 认证清单按类别分组：
  → 强制性认证：CCC证书编号/生产许可证号/特种设备制造许可证号
  → 质量体系：ISO9001/ISO14001/ISO45001证书编号
  → 行业专项：行业准入许可/节能认证/环保认证/信息安全认证
  → 检测报告：型式检验报告/第三方检测报告编号+关键检测项摘要
- 每条认证必须附带四要素：证书编号 | 颁发机构 | 有效期起止 | 覆盖产品范围
- 关键零部件清单：零部件名称 | 品牌/型号 | 产地（国产/进口） | 供应商
- 如涉及进口零部件，说明供货周期和替代方案
- 禁止：笼统说「符合国家标准」——指明标准号和对应条款
- 禁止：使用已过期的证书——生成前逐证核查有效期
- 必须：认证清单和参数响应表中的证据引用自洽
- 风格：认证清单式，每条可在线核验
```

### 三、生产与交付能力

```
你是生产与供应链负责人。请撰写「生产与交付」章节：

【约束】
- 产能数据按公式自洽：
  → 日产能 = 单台设备产量 × 设备数量 × 日运行班次 × 单班有效工时
  → 月产能 = 日产能 × 月工作日
  → 本项目占用比 = 项目需求总量 / 同期可派产能（必须 < 70%，否则评审质疑履约能力）
- 交付计划四要素：
  → 批次划分（每批数量+占总量的比例）
  → 出厂检验节点（每批检验标准和方式）
  → 运输方式（公路/铁路/空运，附运输时间估算依据）
  → 到货时间承诺（按批次列出）
- 包装方案：说明运输包装标准 → 防震/防潮/防静电措施 → 包装示意图的简明文字描述
- 禁止：只说「保证按时交付」而无产能数据——评委会视为无效承诺
- 禁止：产能数据前后矛盾（如日产能×工作日远小于月产能）
- 必须：预留 ≥15% 的产能缓冲应对突发情况
- 风格：排期表+数据表，招标方可据此排验收计划
```

### 四、售后与质保

```
你是售后服务负责人。请撰写「售后与质保」章节：

【约束】
- 质保期明确五要素：
  → 起始计算方式（验收合格之日/货物签收之日）
  → 质保时长（月数）
  → 覆盖范围（整机/核心部件/易损件分别说明）
  → 不覆盖范围（人为损坏/不可抗力/耗材等明确列举）
  → 超出质保期后的服务方式和收费标准
- 服务网络用数据说话：每个网点 → 城市 | 工程师数量 | 响应半径(km) | 到达时限(min)
- 备件库：位置 | 常用备件清单（名称+数量+单价） | 更换时限
- 故障分级及响应：
  → 紧急故障（系统瘫痪）：响应X分钟，到场X小时，恢复X小时
  → 重大故障（核心功能异常）：响应X小时，到场X小时，恢复X小时
  → 一般故障（非核心功能异常）：响应X小时，远程指导或到场
- 培训计划（如有）：对象 | 内容摘要 | 方式 | 时长 | 人数 | 考核方式
- 禁止：承诺「终身质保」而不定义「终身」的起止边界
- 禁止：「充足备件」——必须用清单量化
- 风格：权责分明，边界清楚，每条可考核
```
