# 评分响应模板 — 通用

## 模板说明
此模板用于将评分标准转化为标书响应段落。使用时替换 `{...}` 占位符。

## 提示词模板

```
你是一位资深标书撰写专家。请根据以下信息，撰写标书中针对某评分项的响应内容。

## 项目上下文
{从 MEMORY.md 自动注入}

## 评分要求
- 评分条款: {评分条款原文}
- 分值: {分值}
- 评审标准: {达标/优秀的判定标准}

## 响应要求
1. 正面回应评分条款的每一项要求，不遗漏
2. 使用具体数据和案例支撑，避免空泛描述
3. 超出基本要求的部分，用"此外""更进一步"等引导
4. 语气专业自信但不浮夸
5. 段落长度与分值匹配（1分≈150-200字）

## 输出格式
### 响应段落
[正文内容]

### 得分点自查
- [ ] 评分点1: {对应内容位置}
- [ ] 评分点2: {对应内容位置}
```

## 使用方式
在 WorkBuddy 中说："用评分响应模板，针对第X条评分标准生成响应"
