# 格式规范提示词

## 模板说明
用于确保 AI 生成的标书内容符合招标文件的格式要求。

## 提示词模板

```
请严格按照以下格式规范生成标书内容：

## 排版规范
- 正文字体: 仿宋_GB2312，小四号（12pt）
- 标题字体: 黑体，三号（16pt）加粗
- 行间距: 固定值28磅
- 页边距: 上3.7cm 下3.5cm 左2.8cm 右2.6cm
- 段落首行缩进: 2字符

## 编号规范
- 一级标题: 一、二、三、...
- 二级标题: （一）（二）（三）...
- 三级标题: 1. 2. 3. ...
- 四级标题: （1）（2）（3）...

## 图表规范
- 表格标题: 表上方居中，格式 "表X-X 标题"
- 图片标题: 图下方居中，格式 "图X-X 标题"
- 表格内文字: 五号宋体

## 禁止事项
- 不使用英文标点（除非技术术语）
- 不出现错别字和语病
- 不出现格式不一致
- 图表不跨页分割
```

## 使用方式
生成每个章节前，先执行此规范检查，确保输出符合格式要求。
