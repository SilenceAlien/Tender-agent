## 修复：DOCX 解析 "Package not found" 误导错误

**根因**：python-docx 的 `PackageNotFoundError` 不是文件不存在，而是 `is_zipfile()` 返回 False（文件不是有效 OOXML/ZIP 格式）。错误消息误导。

**修改**：`_load_docx()` 增加三道前置检查：文件存在 → 非空 → is_zipfile，每步有中文错误提示。

## 新增：.doc 格式（Word 97-2003）解析支持

**原因**：用户上传的是旧版 .doc（二进制 OLE 格式），python-docx 无法处理。

**实现**：`_load_doc()` 三层回退策略：
1. macOS textutil（内置，CJK 完美）→ 写临时文件避免 stdout 编码问题
2. Linux antiword（apt install）
3. olefile 原始流提取（pure Python，最后手段）

**修改文件**：
- `core/nodes/doc_parser.py`：新增 `_load_doc()` + `import subprocess, tempfile`；dispatch 拆分 .doc/.docx
- `gui/panels/upload_panel.py`：上传器接受 .doc 格式
- `config/config.yaml`：supported_formats 增加 doc
- `pip install olefile`

验证：23/23 doc_parser 测试通过，337/339 全量通过，中文 .doc 往返测试正常
