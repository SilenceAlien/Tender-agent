## 标书制作智能体 — 方案设计

**目标**：设计一款基于 LangChain + LangGraph 的标书生成智能体。

### 完成内容
1. **三层系统架构**：输入知识层 → LangGraph 编排引擎 → 输出交付层
2. **LangGraph 状态机**：7 节点工作流（DocumentParser → ReqExtractor → TemplateMatcher → SectionGenerator ↔ QualityChecker/FeedbackProcessor → DocumentAssembler）
3. **微调循环机制**：QualityChecker PASS/FAIL 条件路由，反馈分类（内容修正/风格调整/结构优化/评分对齐），精准修改目标段落
4. **多模型供应商适配**：LangChain ChatModel 统一接口封装 6 家供应商（OpenAI / Anthropic / 智谱 / 通义千问 / DeepSeek / Moonshot），ModelRouter 任务级路由，ConfigManager 管理 API Key
5. **GUI 界面原型**：Streamlit 四面板操作台（模型配置 / 资料上传 / 生成审阅 / 导出交付）

### 关键技术选型
- 编排：LangGraph StateGraph + conditional edges
- LLM：LangChain ChatModel（6 providers）
- RAG：FAISS 多索引（模板库 HNSWFlat / 历史库 IVFPQ / 知识库 HNSWFlat）+ 本地 Embedding
- 文档：PyMuPDF + python-docx
- GUI：Streamlit
- 状态持久：SQLite

### FAISS 检索策略（新增）
- 三索引架构：模板库(IndexHNSWFlat, 章节级chunk) / 历史库(IndexIVFPQ, 段落级+Parent Doc) / 知识库(IndexHNSWFlat, 文档级)
- 检索管线：多索引并行 → Parent Document Retrieval → RRF加权融合 → Cross-Encoder重排(BGE-Reranker-v2) → MMR去重(λ=0.7) → 元数据过滤
- 各节点差异化：TemplateMatcher(Index1轻量) / SectionGenerator(全索引+完整管线) / QualityChecker(Index3+法规校验) / FeedbackProcessor(Index2段落级)
- 可选增强：Multi-Vector双索引 / HyDE假设文档 / Self-Query元数据抽取

### 产品演进与部署策略（新增）
- 三阶段演进：Phase1 自用验证(本地Streamlit) → Phase2 SaaS按次计费(云端部署) → Phase3 本地化打包(Docker镜像买断)
- 核心原则：一套代码 core/ 不变，通过 adapters/ 注入部署差异（计费/License/存储）
- SaaS 独有：账户体系、按次计费、云端模板库在线更新
- 本地化独有：Docker Compose 一键部署、License 机器指纹绑定、数据零外泄、离线升级包
- 关键约束：核心引擎零云依赖、LLM API Key 用户自管、FAISS 始终本地磁盘
